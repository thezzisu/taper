First preview release of taper for Linux, with binaries for amd64 and arm64.

- Pack files into LTO archives while keeping an encrypted, searchable SQLite
  catalog offline. Small files share records, and planning deduplicates content.
- Replica sets share immutable archive streams across tapes and sparse `.img`
  caches. Synchronize complete archives without recompression and prune only
  image data committed on every member tape.
- Mount original files through read-only FUSE, including partially cached images.
  Missing blocks report `ENODATA`; corrupt data reports `EIO`.
- Browse nested archive contents using embedded 7-Zip, without an external `7z`
  executable or CGO. The CLI supports JSON, dry runs and tape-operation previews.

Validation includes simulated media, race detection, actual Linux kernel FUSE
tests, decoder fuzzing and bounded acceptance of a seven-archive 2.45 TB image.
Physical hardware qualification is currently LTO-6 on Linux amd64; arm64 binaries
are cross-built. No physical tape is accessed by CI.

This is a preview, not a stable compatibility promise. Tape, image and catalog
versions remain 1; no implicit catalog migration is performed. Back up the catalog
and recovery key separately. Format v1 does not preserve permissions, ownership,
empty directories or original sparse-file layout. See the included format and
operations documentation for encryption and recovery limits.

Taper is licensed under Apache-2.0. Embedded dependencies retain their own
licenses, included in each binary archive. Check downloads with
`sha256sum --check checksums.txt`; `taper --version` reports `v0.1.0`.
